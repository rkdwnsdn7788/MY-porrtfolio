03 · PROJECT

AI 활용 이미지 분류 프로젝트

용접부 이미지를 5개 클래스로 분류하고, 실험 조건과 성능 변화를 비교한 CNN 실습 프로젝트입니다.

실험 조건을 조정해 분류 성능을 개선한 경험

용접부 이미지를 기공, 언더컷, 용입부족, 융합불량, 정상의 5개 클래스로 분류하는 CNN 실습을 수행했습니다. 기준 실험 이후 10회의 개선 실험을 진행하며 설정과 성능 지표를 비교했습니다.

프로젝트
CNN 기반 용접 결함 이미지 5종 분류
상세 내용
이미지 크기, 배치 크기, CNN 채널, 학습률, Epoch, 스케줄러와 손실 함수를 단계적으로 조정했습니다. 실험 10에서 Macro F1 0.9295, Accuracy 0.930으로 최고 성능을 기록했습니다.
직무 연결
조건별 결과를 기록하고 품질 지표로 비교한 경험은 생산관리 직무의 불량 원인 분석, 공정 조건 개선, 개선 결과 공유 업무와 연결됩니다.

수업 실습에서 AI로 생성한 자료, 회사 공식 자료 아님
